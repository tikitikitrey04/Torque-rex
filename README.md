# Torque-rex

Torque-rex is an ESP32-S3-based dynamometer test suite being developed for ECE3332 Electric Machines at Western University. It aims to help characterize student-built BLDC motors through motor speed, torque, electrical input power, mechanical output power, and efficiency measurements.

## Architecture

The ESP32-S3-N16R8 (16 MB flash, 8 MB PSRAM) runs Arduino firmware, creates its own Wi-Fi access point, and serves compiled React files from LittleFS over HTTP. The connected user's browser downloads and executes React. Standalone operation requires no installed client software, external Wi-Fi network, router, internet connection, or separate application server.

Development uses VS Code, PlatformIO, Arduino C++, React, TypeScript, and Vite. Vite runs on the development computer; it is not needed on the ESP32.

## Development status

Reported successful hardware tests include USB programming, detection of 16 MB flash and 8 MB PSRAM, Vite production builds, and serving the React application from LittleFS at `http://192.168.4.1` on the `Torque-rex` access point.

The current code implements static HTTP hosting, a fallback for client-side routes, and a browser serial-output page backed by a bounded application log endpoint (`/api/serial`). The frontend provides a minimal workspace with centralized design tokens, reusable UI components, and persistent light/dark/system appearance. Sensor acquisition, motor control, live measurements, test automation, a functional sensor-data API, and WebSockets are planned. OTA updates are not implemented.

## Developer quick start

1. Install VS Code with PlatformIO IDE, plus Node.js and npm as described in the [frontend guide](frontend/README.md).
2. In `frontend/`, run `npm ci` and `npm run dev` for local UI development.
3. Open `firmware/` as a PlatformIO project and upload firmware over USB using the [firmware guide](firmware/README.md).
4. Build the frontend, copy the contents of `frontend/dist/` into `firmware/data/`, and upload the filesystem image. See the [frontend deployment steps](frontend/README.md#deploy-to-the-esp32).
5. Connect to Wi-Fi `Torque-rex` with password `TorqueRex2026`, then open `http://192.168.4.1`.
